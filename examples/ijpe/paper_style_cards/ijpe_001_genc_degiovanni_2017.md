## A. Abstract Style

- **Opening move:** Starts from consumer/product-return behavior, then introduces the model.
- **Structure:** Context -> model setup -> decision question -> findings -> competition extension.
- **Contribution placement:** The contribution is embedded in the model description rather than framed as a separate list.
- **Register:** Technical production-economics register with compact model terminology.

## B. Introduction Architecture

- **Hook type:** Closed-loop supply chain concept and research agenda.
- **Opening move:** Defines the operational system, then names core unresolved CLSC questions.
- **Problem-consequence framing:** Uses economic recovery, legislation, and partner pressure as reasons the problem matters.
- **Gap identification:** Moves from existing CLSC collection-structure studies to the paper's endogenous-return and dynamic-game setting.
- **Contribution placement:** Middle-to-late, after literature positioning.
- **Contribution format:** Prose paragraphs organized as first/second/third contribution.
- **Roadmap:** Conventional final roadmap.
- **Literature positioning:** Integrated into introduction before a separate model section.

## C. Contribution Expression

- **Voice:** Author-centered "our contribution" style, but tied to explicit model features.
- **Claim strength:** Direct but bounded by model assumptions.
- **Format:** Numbered-in-prose contribution sequence.
- **Novelty framing:** Newness is framed through decision variables, dynamic timing, and competition setting.

## D. Method / Model Presentation

- **Entry point:** Conceptual CLSC structure and managerial questions before formal model.
- **Notation density:** Formal notation begins after the introduction.
- **Formal exposition style:** Stackelberg/two-period game, followed by cases and comparison.
- **Explanation of assumptions:** Assumptions are motivated through prior CLSC literature and practical examples.

## E. Results Presentation

- **Primary vehicle:** Analytical model results plus comparison across channel structures.
- **Narrative style:** Decision setting -> model case -> managerial implication.
- **Mechanism emphasis:** Collection responsibility, incentive scheme, return-rate endogeneity.

## F. Language Style Tags

- **Register:** Technical operations/supply-chain.
- **Sentence length:** Medium to long.
- **Voice:** Mixed active and passive.
- **Hedging level:** Moderate.
- **Transition style:** Explicit contribution sequencing and conventional roadmap.

## G. Distinctive Patterns

- Introduction can be long when it builds from operational concept to model contribution.
- Research questions appear near the end of the introduction after contribution logic is established.
- Contribution paragraphs are acceptable when each one maps to a model innovation.
